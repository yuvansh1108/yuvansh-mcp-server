# Chatty Pi UI

This directory contains the first UI shell for Chatty Pi.

## Security

Do not put the Chatty Pi database/API key in these browser-served files. The UI must call a server-side API/service that keeps privileged credentials in environment variables or hosting secrets.

## Next integration step

Wire the server-side API to authenticated Chatty Pi data endpoints for conversations, messages, profiles, notifications, and communities.
